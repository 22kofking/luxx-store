# LUXX STORE

Landing page da LUXX STORE (streetwear, preto e amarelo raio) com painel de controle embutido, tudo em um único arquivo: `LUXX STORE SITE.html`.

## Como usar

1. Abra `LUXX STORE SITE.html` no navegador (celular ou computador).
2. Toque em **Editar site** (canto inferior esquerdo) para abrir o painel.
3. Mude o que quiser: marca, WhatsApp, redes sociais, cores, fontes, estilo, banner, seções, categorias, catálogo, promoção, rodapé e CSS livre.
4. As alterações ficam salvas no navegador em que você editou.
5. Para publicar, vá em **Publicar → Baixar site atualizado**. O arquivo baixado já leva todas as mudanças (inclusive as fotos) e pode ser enviado para qualquer hospedagem estática (Netlify Drop, GitHub Pages, Hostinger etc.).

Se esconder o botão **Editar site**, abra o painel tocando 5 vezes na logo ou colocando `#painel` no fim do endereço.

Importante: troque o número de WhatsApp de exemplo (`5511900000000`) na aba **Marca** antes de publicar.
